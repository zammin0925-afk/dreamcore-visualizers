================================================================
  몽환 비주얼라이저 & 드림코어 컬렉션 (Dreamcore Visualizer Pack)
================================================================

본 패키지의 모든 파일은 [100% 단일 파일(Single HTML5)]로 제작되었습니다.
인터넷 연결, 별도 프로그램 설치, Node.js나 서버 환경이 전혀 필요 없으며,
어떤 노트북이나 PC(Windows, Mac)에서도 바로 실행할 수 있습니다.

[간편 실행 방법]
1. Windows 노트북 / PC:
   - 각 모드별 .bat 파일을 더블 클릭하면 브라우저가 자동으로 열립니다.
   - 또는 .html 파일을 크롬(Chrome), 엣지(Edge), 웨일(Whale) 등으로 바로 더블 클릭해 여셔도 됩니다.

2. Mac / 스마트폰 / 태블릿:
   - .html 파일을 Safari나 Chrome 브라우저로 열면 동일하게 작동합니다.

----------------------------------------------------------------
[주요 파일 목록 및 바로가기]
----------------------------------------------------------------
1. 드림코어 & 영화관 & 눈 내리는 숲길
   - run_dreamcore.bat / dreamcore_sanctuary.html : 5가지 풍경 통합 드림코어 플레이어
     * 풍경 1: 바다 위 잠긴 철길 & 거대 전광판 모놀리스 (단축키 [1])
     * 풍경 2: 황혼의 전신주와 비 & 하늘 위 대형 전광판 (단축키 [2])
     * 풍경 3: 안개 낀 간이역 벤치 & 정거장 전광판 (단축키 [3])
     * 풍경 4: 심야의 빈 영화관 & 벨벳 객석과 EXIT 철문 (단축키 [4])
     * 풍경 5: 눈 내리는 푸른 숲길 & 고독한 인물 (dreamscape) (단축키 [5])
   - run_cinema.bat : 심야 영화관 모드 직행 실행기
   - run_snow.bat   : 눈 내리는 숲길(dreamscape) 모드 직행 실행기
   * 단축키 [V]를 누르면 내 영상 파일(MP4, WebM)을 전광판/스크린에 바로 띄울 수 있습니다.

2. 웅장한 서사시 비주얼라이저 (Hopes and Dreams)
   - run_epic_hope.bat / epic_hopes_and_dreams.html : 은하수와 별빛, 감동적인 오케스트라 비주얼

3. 폰크 드리프트 & 사이버펑크 네온
   - run_phonk_station.bat / phonk_drift_station.html : 강렬한 베이스 반응형 드리프트 비주얼라이저

4. 힐링 & 캠프파이어
   - run_campfire.bat / healing_campfire.html : 3D 불멍 & 인터랙티브 캠프파이어
   - run_healing_time.bat / healing_time_background.html : 24시간 실시간 시간대 반영 감성 배경

5. 오디오 분석 & 비디오 비주얼라이저
   - run_dual_mirror.bat / dual_mirror_video_visualizer.html : 듀얼 미러 비디오 스펙트럼
   - run_visualizer.bat / audio_spectrum_visualizer.html : 정밀 오디오 스펙트럼
   - run_stem_analyzer.bat / audio_stem_wave_analyzer.html : 4트랙 파형 분석기
