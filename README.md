## ✨ 드림코어 5대 풍경 (`dreamcore_sanctuary.html`)

1. **🌊 바다 위 잠긴 철길 (단축키 `[1]`)**  
   철길 끝 바다 위에 솟은 거대 전광판 모놀리스와 일렁이는 수면 반사광
2. **🚏 황혼의 전신주와 비 (단축키 `[2]`)**  
   보랏빛 노을 하늘에 뜬 대형 전광판과 도시 철골 기둥, 비 내리는 전신주 실루엣
3. **🍂 안개 낀 간이역 (단축키 `[3]`)**  
   새벽 4:44 AM 안개 자욱한 승강장 벤치와 가로등 옆 대형 정거장 광고판
4. **🎬 심야의 영화관 (단축키 `[4]`)**  
   텅 빈 벨벳 객석과 대형 실버 스크린, 영사기 광선과 벽면 초록빛 EXIT 비상구 철문
5. **❄️ 눈 내리는 숲길 (dreamscape, 단축키 `[5]`)**  
   짙은 푸른 안개 숲길, 고독한 뒷모습 실루엣, 흩날리는 눈송이와 도로변 전광판

> **내 동영상(MP4, WebM) 실시간 상영**: `[V]` 키를 누르면 내 영상이 전광판과 영화관 스크린에 즉시 상영됩니다. 영상이 없을 때도 1997 레트로 VHS 드림코어 영상이 자동 루프 재생됩니다.

## 📱 스마트폰 / 모바일 폰 모드

- **화면 탭 한 번으로 UI 숨김**: 스마트폰에서 화면을 가볍게 탭하면 모든 조작 UI가 숨겨져 **전체화면 감성 라이브 배경화면**으로 변신합니다.
- **9:16 세로 뷰포트 최적화**: 영화관 객석 비율, 안개 간이역 전광판, 소실점 철길/숲길이 세로 화면에 맞춰 완벽하게 렌더링됩니다.
- **PC에서 폰 모드 토글**: PC에서도 `[M]` 키 또는 상단 `📱 폰 모드` 버튼을 누르면 9:16 스마트폰 프레임 안에서 세로 감상 가능합니다.

## ⌨️ 단축키 안내

| 키 | 기능 |
| :--- | :--- |
| **`Space`** | 음악 재생 / 일시정지 |
| **`V`** | 내 동영상 파일(MP4, WebM) 불러와 스크린에 띄우기 |
| **`1 ~ 5`** | 5대 풍경 전환 (1: 바다철길 / 2: 황혼전신주 / 3: 간이역 / 4: 영화관 / 5: 눈숲길) |
| **`M`** | 📱 폰 모드 토글 (9:16 세로 뷰 전환) |
| **`H`** | UI 숨김 / 순수 감상 모드 (Zen Mode) |
| **`P`** | 트랙 목록 및 파일 추가 서랍 열기/닫기 |
| **`F`** | 전체화면 모드 |

## 💻 로컬 PC 실행 방법

```bash
git clone https://github.com/zammin0925-afk/dreamcore-visualizers.git
cd dreamcore-visualizers
```

폴더 내의 원하는 `.bat` 파일(예: `run_dreamcore.bat`, `run_phone_mode.bat`, `run_snow.bat`)을 더블 클릭하면 브라우저에서 즉시 실행됩니다.
